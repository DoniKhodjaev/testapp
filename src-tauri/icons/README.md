# Иконки приложения

Для корректной работы Tauri необходимы следующие иконки:

- `32x32.png` - иконка 32x32
- `128x128.png` - иконка 128x128
- `128x128@2x.png` - иконка 256x256 (для Retina дисплеев)
- `icon.icns` - иконка для macOS
- `icon.ico` - иконка для Windows

## Автоматическая генерация иконок

Вы можете использовать любое изображение (желательно PNG 512x512) и сгенерировать все необходимые иконки с помощью:

```bash
npm install -g @tauri-apps/cli
npm run tauri icon path/to/your/icon.png
```

Это автоматически создаст все необходимые форматы иконок.

## Дизайн иконки

Рекомендуется создать иконку с:
- Символом "HR" на синем фоне
- Или иконку документа/папки с буквами "HR"
- Минималистичный стиль
- Хорошая читаемость в маленьких размерах
