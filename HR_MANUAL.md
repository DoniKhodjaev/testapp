# Руководство для HR отдела
## HR Система управления заявлениями

---

## 📋 Что это такое?

**HR Система управления заявлениями** — это компьютерная программа, которая помогает автоматизировать процесс создания заявлений сотрудников (на отпуск, командировку, больничный и т.д.).

**Простыми словами:** Вместо того, чтобы сотрудники писали заявления от руки или в Word, они заполняют форму на компьютере, а система сама создает готовый документ.

---

## 🎯 Зачем это нужно?

### Проблемы, которые решает система:

❌ **Раньше:**
- Сотрудники писали заявления вручную или искали шаблоны в интернете
- Каждый раз нужно было вписывать свои данные (ФИО, должность, подразделение)
- Документы получались неодинаковыми по формату
- HR тратил время на проверку правильности заполнения

✅ **Теперь:**
- Сотрудник выбирает шаблон, заполняет несколько полей — и готово!
- Все данные сотрудника подставляются автоматически
- Все документы в едином формате
- Меньше ошибок, больше времени на важные задачи

## 🚀 Установка программы

### Первый запуск

1. Скачайте установочный файл (`.exe` или `.msi`)
2. Запустите установщик
3. Следуйте инструкциям на экране
4. После установки запустите программу

### Где находятся данные

Все данные хранятся на вашем компьютере в папке:
- **Windows:** `C:\Users\ИМЯ_ПОЛЬЗОВАТЕЛЯ\AppData\Local\hr-forms-management`

## 👥 Как пользоваться программой

### Переключение режимов

При запуске программы вы видите **режим сотрудника**. Чтобы перейти в режим администратора:

1. Нажмите кнопку **"Панель HR"** в правом верхнем углу
2. Теперь вы в режиме администратора
3. Чтобы вернуться: нажмите **"Режим сотрудника"**

## 📝 Управление сотрудниками

### Добавление нового сотрудника

1. Откройте **Панель HR**
2. Перейдите на вкладку **"Сотрудники"**
3. Нажмите кнопку **"+ Добавить сотрудника"**
4. Заполните поля:
   - **ФИО** * — полное имя (например: Иванов Иван Иванович)
   - **Должность** * — должность сотрудника (например: Менеджер)
   - **Подразделение** * — отдел (например: Отдел продаж)
   - **Управление** * — управление (например: Коммерческое управление)
   - **Email** — рабочая почта (необязательно)
   - **Телефон** — рабочий телефон (необязательно)
   - **Руководитель** — выберите из списка существующих сотрудников (необязательно)
5. Нажмите **"Сохранить"**

> **Примечание:** Поля, отмеченные звездочкой (*), обязательны для заполнения.

### Редактирование сотрудника

1. Найдите нужного сотрудника в таблице
2. Нажмите на иконку **карандаша** (редактировать)
3. Измените нужные данные
4. Нажмите **"Сохранить"**

### Удаление сотрудника

1. Найдите нужного сотрудника в таблице
2. Нажмите на иконку **корзины** (удалить)
3. Подтвердите удаление

> **Важно:** Будьте осторожны при удалении! Восстановить данные будет невозможно.

## 📄 Управление шаблонами заявлений

### Создание нового шаблона

1. Откройте **Панель HR**
2. Перейдите на вкладку **"Шаблоны форм"**
3. Нажмите **"+ Создать шаблон"**
4. Заполните информацию о шаблоне:
   - **Название шаблона** — например: "Заявление на оплачиваемый отпуск"
   - **Описание** — краткое описание для сотрудников

### Добавление полей в шаблон

После создания шаблона вы попадете в **Визуальный редактор**:

1. Нажмите **"+ Добавить поле"**
2. Настройте поле:
   - **Название поля** — как оно будет отображаться (например: "Дата начала отпуска")
   - **Имя переменной** — техническое название (автоматически)
   - **Тип поля** — выберите подходящий:
     - **Текст** — короткий текст (ФИО, номер)
     - **Многострочный текст** — длинный текст (комментарии, причины)
     - **Дата** — выбор даты из календаря
     - **Число** — только цифры (количество дней)
     - **Выпадающий список** — выбор из вариантов (тип отпуска)
     - **Выбор сотрудника** — выбор из базы сотрудников
   - **Подсказка** — текст-подсказка для сотрудника
   - **Обязательное поле** — поставьте галочку, если поле обязательно

3. Для типа **"Выпадающий список"**:
   - В поле "Варианты" введите варианты, каждый с новой строки
   - Например:
     ```
     Оплачиваемый отпуск
     Отпуск без содержания
     Учебный отпуск
     ```

4. Добавьте все необходимые поля

5. Измените порядок полей кнопками **↑ ↓**

6. Нажмите **"Сохранить"**

### Пример: Заявление на отпуск

**Поля для создания:**

1. **Тип отпуска**
   - Тип: Выпадающий список
   - Варианты: Оплачиваемый, Без сохранения содержания, Учебный
   - Обязательное: Да

2. **Дата начала**
   - Тип: Дата
   - Обязательное: Да

3. **Дата окончания**
   - Тип: Дата
   - Обязательное: Да

4. **Количество дней**
   - Тип: Число
   - Обязательное: Да

5. **Комментарий**
   - Тип: Многострочный текст
   - Обязательное: Нет

### Редактирование шаблона

1. Найдите нужный шаблон в списке
2. Нажмите иконку **карандаша**
3. Внесите изменения
4. Нажмите **"Сохранить"**

### Активация/Деактивация шаблона

Чтобы **скрыть** шаблон от сотрудников (например, старый или устаревший):

1. Найдите шаблон в списке
2. Нажмите иконку **глаза** (скрыть/показать)
3. Скрытые шаблоны помечаются серым цветом

> **Примечание:** Скрытые шаблоны не отображаются для сотрудников, но сохраняются в базе.

### Удаление шаблона

1. Найдите шаблон в списке
2. Нажмите иконку **корзины**
3. Подтвердите удаление

## 👤 Как работает сотрудник с программой

### Шаг 1: Выбор шаблона

1. Сотрудник открывает программу (режим сотрудника)
2. Видит карточки с доступными типами заявлений
3. Выбирает нужный шаблон (например: "Заявление на отпуск")

### Шаг 2: Заполнение формы

1. Выбирает себя из списка сотрудников
2. Видит автоматически заполненные данные:
   - ФИО
   - Должность
   - Подразделение
   - Управление
3. Заполняет дополнительные поля (даты, комментарии и т.д.)

### Шаг 3: Предварительный просмотр

1. Нажимает **"Предварительный просмотр"**
2. Видит готовый документ

### Шаг 4: Сохранение

Выбирает один из вариантов:
- **PDF** — сохранить как PDF файл (для отправки по почте)
- **DOCX** — сохранить как Word документ (для редактирования)
- **Печать** — распечатать сразу

## ❓ Часто задаваемые вопросы

### Что делать, если программа не запускается?

1. Проверьте, что у вас установлена последняя версия
2. Перезагрузите компьютер
3. Переустановите программу

### Можно ли восстановить удаленного сотрудника?

Нет, после удаления данные невозможно восстановить. Будьте внимательны!

### Как создать резервную копию данных?

Скопируйте папку с данными:
- Windows: `C:\Users\ИМЯ_ПОЛЬЗОВАТЕЛЯ\AppData\Local\hr-forms-management`

Сохраните копию на флешку или в облако.

### Можно ли использовать программу на нескольких компьютерах?

Каждая установка хранит данные локально. Для работы на нескольких компьютерах нужно:
1. Экспортировать базу с одного компьютера
2. Импортировать на другой

(Функция импорта/экспорта может быть добавлена в будущих версиях)

### Как добавить логотип компании в документы?

Эта функция будет добавлена в будущих версиях программы.

### Сколько сотрудников можно добавить?

Нет ограничений! Можно добавлять любое количество сотрудников.

### Сколько шаблонов можно создать?

Нет ограничений! Создавайте столько шаблонов, сколько нужно.

## 💡 Советы и лучшие практики

### Именование шаблонов

✅ **Хорошо:**
- "Заявление на оплачиваемый отпуск"
- "Заявление на командировку по РФ"
- "Заявление на материальную помощь"

❌ **Плохо:**
- "Отпуск"
- "Заявление 1"
- "Новый шаблон"

### Описание шаблонов

Пишите понятное описание для сотрудников:

✅ **Хорошо:**
"Используйте этот шаблон для оформления ежегодного оплачиваемого отпуска"

❌ **Плохо:**
"Отпуск"

### Обязательные поля

Делайте обязательными только действительно необходимые поля. Слишком много обязательных полей усложняет работу сотрудников.

### Подсказки

Используйте подсказки для пояснения:
- "Укажите дату в формате ДД.ММ.ГГГГ"
- "Количество календарных дней"
- "Выберите тип отпуска из списка"
