# HR Система управления заявлениями

Десктопное приложение для автоматизации процесса создания и управления заявлениями сотрудников в банке.

## 🚀 Технологии

- **Frontend**: React + TypeScript + TailwindCSS + ShadCN/UI
- **Desktop Framework**: Tauri
- **State Management**: Zustand
- **Database**: SQLite (через Rust)
- **Export**: PDF (jsPDF) и DOCX (docx.js)

## ✨ Функциональность

### Для сотрудников
- ✅ Выбор шаблона заявления из списка
- ✅ Автоматическое заполнение данных сотрудника (ФИО, должность, подразделение)
- ✅ Простая форма для заполнения
- ✅ Предварительный просмотр документа
- ✅ Экспорт в PDF/DOCX
- ✅ Печать документа

### Для HR отдела (Админ-панель)
- ✅ Управление базой сотрудников (добавление, редактирование, удаление)
- ✅ Визуальный редактор шаблонов форм
- ✅ Создание кастомных полей (текст, дата, число, выбор из списка и т.д.)
- ✅ Активация/деактивация шаблонов
- ✅ Назначение руководителей

## 📦 Установка и запуск

### Требования
- Node.js 18+
- Rust (для Tauri)
- npm или yarn

### Установка зависимостей

```bash
npm install
```

### Разработка

```bash
npm run tauri:dev
```

### Сборка приложения

```bash
npm run tauri:build
```

После сборки exe файл будет находиться в `src-tauri/target/release/bundle/`

## 📖 Использование

### Режим сотрудника

1. Откройте приложение
2. Выберите нужный шаблон заявления из списка
3. Выберите себя из списка сотрудников
4. Заполните необходимые поля
5. Нажмите "Предварительный просмотр"
6. Выберите формат экспорта: PDF, DOCX или Печать

### Режим HR (Админ-панель)

Переключитесь в режим администратора кнопкой "Панель HR" в шапке приложения.

#### Управление сотрудниками

1. Перейдите на вкладку "Сотрудники"
2. Нажмите "Добавить сотрудника"
3. Заполните данные:
   - ФИО *
   - Должность *
   - Подразделение *
   - Управление *
   - Email (опционально)
   - Телефон (опционально)
   - Руководитель (опционально)
4. Нажмите "Сохранить"

#### Создание шаблонов форм

1. Перейдите на вкладку "Шаблоны форм"
2. Нажмите "Создать шаблон"
3. Заполните название и описание шаблона
4. Добавьте поля формы:
   - Нажмите "Добавить поле"
   - Настройте параметры поля (название, тип, обязательность)
   - Доступные типы полей:
     - Текст
     - Многострочный текст
     - Дата
     - Число
     - Выпадающий список (с кастомными опциями)
     - Выбор сотрудника
5. Упорядочьте поля стрелками вверх/вниз
6. Нажмите "Сохранить"

## 💾 База данных

Приложение использует SQLite для хранения данных. База автоматически создается при первом запуске в:

- **Windows**: `%LOCALAPPDATA%\hr-forms-management\database.db`
- **macOS**: `~/Library/Application Support/hr-forms-management/database.db`
- **Linux**: `~/.local/share/hr-forms-management/database.db`

### Таблицы:
- `employees` - сотрудники
- `templates` - шаблоны форм
- `filled_forms` - история заполненных форм

## 🎨 Кастомизация

### Изменение цветовой схемы

Отредактируйте файл `src/index.css` в секции CSS переменных:

```css
:root {
  --primary: 221.2 83.2% 53.3%;
  /* и другие переменные */
}
```

### Добавление новых типов полей

1. Добавьте тип в `src/types/index.ts`
2. Добавьте рендеринг в `src/components/FormFilling.tsx`
3. Добавьте опцию в `src/components/admin/TemplateEditor.tsx`
